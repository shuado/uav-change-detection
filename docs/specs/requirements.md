# 需求规格说明书 v2.0

## 1. 项目概述

### 1.1 背景
无人机正射影像变化检测是林业资源监测、城市规划、环境保护等领域的重要技术手段。

### 1.2 目标
构建基于深度学习的图斑级变化检测系统，支持林地、草地、水域、道路、建筑五类地物的变化识别，整体识别率≥90%。

### 1.3 范围
- 输入：两期无人机正射影像（RGB，GSD 2-5cm）
- 输出：图斑级变化检测报告 + GeoJSON + 对比切片图
- 支持变化类型：新增、消失、类型转换、面积变化

## 2. 功能需求

### 2.1 数据管理
- **F2.1.1** 支持 TIFF/GeoTIFF 格式影像导入
- **F2.1.2** **自动识别所有TIF的经纬度坐标系**
- **F2.1.3** **全部坐标系归一化为WGS84（EPSG:4326）**
- **F2.1.4** 支持多波段影像处理（RGB + NIR 可选）

### 2.2 预处理
- **F2.2.1** 影像配准（基于 RTK/PPK 定位或特征点匹配）
- **F2.2.2** 辐射校正（直方图均衡化、白平衡）
- **F2.2.3** 影像裁剪（按 ROI 或行政区划）
- **F2.2.4** 数据增强（旋转、翻转、色彩抖动）

### 2.3 语义分割
- **F2.3.1** 支持 SegFormer、U-Net 等主流模型
- **F2.3.2** 支持 5 类地物分割
- **F2.3.3** 支持模型微调和迁移学习
- **F2.3.4** 输出像素级分割掩膜

### 2.4 图斑矢量化
- **F2.4.1** 从分割掩膜提取图斑边界
- **F2.4.2** 图斑平滑和简化
- **F2.4.3** 小图斑过滤（面积阈值可配置）
- **F2.4.4** **输出矢量图斑坐标为WGS84经纬度**

### 2.5 变化检测
- **F2.5.1** 图斑级对比（面积、类型、边界）
- **F2.5.2** 变化类型分类：新增、消失、类型转换、面积变化
- **F2.5.3** 变化置信度评估
- **F2.5.4** **输出GeoJSON格式的变化多边形（WGS84坐标）**

### 2.6 报告生成（新增）
- **F2.6.1** **前后对比切片图片**（左右对比/Toggle对比）
- **F2.6.2** **变化面积统计**（各地物类型变化面积）
- **F2.6.3** **变化经纬度坐标**（每个变化图斑的质心和边界坐标）
- **F2.6.4** 统计汇总表（各地物变化面积、数量）
- **F2.6.5** 变化图斑清单
- **F2.6.6** 可视化地图
- **F2.6.7** 支持导出 PDF/Excel/HTML 格式

### 2.7 REST API服务（新增）
- **F2.7.1** **基于FastAPI的REST API服务**
- **F2.7.2** 影像上传接口（POST /api/v1/upload）
- **F2.7.3** 变化检测接口（POST /api/v1/detect）
- **F2.7.4** 任务状态查询接口（GET /api/v1/tasks/{id}）
- **F2.7.5** 结果下载接口（GET /api/v1/results/{id}）
- **F2.7.6** GeoJSON导出接口（GET /api/v1/results/{id}/geojson）
- **F2.7.7** 报告下载接口（GET /api/v1/results/{id}/report）
- **F2.7.8** 自动API文档（Swagger UI / ReDoc）
- **F2.7.9** API认证（API Key）
- **F2.7.10** 异步任务处理（Celery）

## 4. 坐标系处理规范（新增）

### 4.1 坐标系自动识别
```
输入TIF → 读取元数据 → 检测CRS → 记录原始坐标系
```

支持的坐标系：
- WGS84 (EPSG:4326)
- UTM (各分带)
- CGCS2000 (EPSG:4490)
- 北京54
- 西安80
- 地方坐标系

### 4.2 坐标系归一化
```
原始坐标系 → 坐标转换 → WGS84 (EPSG:4326)
```

- 使用 pyproj 进行坐标转换
- 自动处理7参数/3参数转换
- 转换精度记录在元数据中

## 5. API接口规范（新增）

### 5.1 接口列表

| 方法 | 路径 | 描述 |
|:---|:---|:---|
| POST | /api/v1/upload | 上传影像 |
| POST | /api/v1/detect | 提交变化检测任务 |
| GET | /api/v1/tasks/{id} | 查询任务状态 |
| GET | /api/v1/results/{id} | 获取检测结果 |
| GET | /api/v1/results/{id}/geojson | 下载GeoJSON |
| GET | /api/v1/results/{id}/report | 下载报告 |
| GET | /api/v1/results/{id}/images | 下载对比图片 |
| DELETE | /api/v1/tasks/{id} | 取消任务 |

### 5.2 请求/响应格式

```json
// POST /api/v1/detect
{
    "image_t1": "file_id_1",
    "image_t2": "file_id_2",
    "options": {
        "model": "segformer",
        "confidence_threshold": 0.7,
        "min_area": 100
    }
}

// Response
{
    "task_id": "uuid",
    "status": "processing",
    "created_at": "2026-07-22T10:00:00Z"
}
```

## 7. 报告输出规范（新增）

### 7.1 对比切片图
- 格式：PNG
- 分辨率：1024x1024
- 内容：左右对比（T1 | T2）
- 叠加：变化图斑边界（红色）+ 类别标注

### 7.2 统计报表
- 变化面积（按地物类型）
- 变化数量（按变化类型）
- 变化分布（热力图）

### 7.3 坐标信息
- 每个变化图斑的质心坐标（经纬度）
- 边界坐标序列
- 面积（平方米）
