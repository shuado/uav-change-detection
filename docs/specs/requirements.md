# 需求规格说明书

## 1. 项目概述

### 1.1 背景
无人机正射影像变化检测是林业资源监测、城市规划、环境保护等领域的重要技术手段。传统人工对比效率低、主观性强，需要自动化、高精度的变化检测系统。

### 1.2 目标
构建基于深度学习的图斑级变化检测系统，支持林地、草地、水域、道路、建筑五类地物的变化识别，整体识别率≥90%。

### 1.3 范围
- 输入：两期无人机正射影像（RGB，GSD 2-5cm）
- 输出：图斑级变化检测报告
- 支持变化类型：新增、消失、类型转换、面积变化

## 2. 功能需求

### 2.1 数据管理
- **F2.1.1** 支持 TIFF/GeoTIFF 格式影像导入
- **F2.1.2** 自动提取影像元数据（坐标系、分辨率、拍摄时间）
- **F2.1.3** 支持多波段影像处理（RGB + NIR 可选）

### 2.2 预处理
- **F2.2.1** 影像配准（基于 RTK/PPK 定位或特征点匹配）
- **F2.2.2** 辐射校正（直方图均衡化、白平衡）
- **F2.2.3** 影像裁剪（按 ROI 或行政区划）
- **F2.2.4** 数据增强（旋转、翻转、色彩抖动）

### 2.3 语义分割
- **F2.3.1** 支持 SegFormer、U-Net 等主流模型
- **F2.3.2** 支持 5 类地物分割（林地、草地、水域、道路、建筑）
- **F2.3.3** 支持模型微调和迁移学习
- **F2.3.4** 输出像素级分割掩膜

### 2.4 图斑矢量化
- **F2.4.1** 从分割掩膜提取图斑边界
- **F2.4.2** 图斑平滑和简化（Douglas-Peucker 算法）
- **F2.4.3** 小图斑过滤（面积阈值可配置）
- **F2.4.4** 输出矢量图斑（Shapefile/GeoJSON）

### 2.5 变化检测
- **F2.5.1** 图斑级对比（面积、类型、边界）
- **F2.5.2** 变化类型分类：
  - 新增图斑（t1 无，t2 有）
  - 消失图斑（t1 有，t2 无）
  - 类型转换（如林地→建筑）
  - 面积变化（扩大/缩小 >20%）
- **F2.5.3** 变化置信度评估

### 2.6 报告生成
- **F2.6.1** 统计汇总表（各地物变化面积、数量）
- **F2.6.2** 变化图斑清单（位置、类型、面积、置信度）
- **F2.6.3** 可视化地图（叠加两期影像和变化图斑）
- **F2.6.4** 支持导出 PDF/Excel 格式

## 3. 非功能需求

### 3.1 性能
- **N3.1.1** 单张影像（10000x10000 像素）处理时间 < 5 分钟
- **N3.1.2** 整体识别率 ≥ 90%（IoU ≥ 0.82）
- **N3.1.3** 支持批量处理（≥ 100 对影像）

### 3.2 可用性
- **N3.2.1** 提供命令行接口（CLI）
- **N3.2.2** 提供 Python API 接口
- **N3.2.3** 提供可视化界面（可选，Web/GUI）

### 3.3 可扩展性
- **N3.3.1** 支持自定义地物类型
- **N3.3.2** 支持插件式模型扩展
- **N3.3.3** 支持多 GPU 并行训练

### 3.4 可靠性
- **N3.4.1** 测试覆盖率 ≥ 80%
- **N3.4.2** 异常处理和日志记录
- **N3.4.3** 支持断点续训和模型备份

## 4. 约束条件

### 4.1 数据约束
- 影像分辨率：GSD 2-5cm
- 影像格式：TIFF/GeoTIFF
- 坐标系：WGS84 或 UTM

### 4.2 硬件约束
- GPU 显存：≥ 24GB（训练）/ ≥ 8GB（推理）
- 内存：≥ 32GB
- 存储：≥ 1TB（数据集）

### 4.3 时间约束
- 第一阶段（基础功能）：2-3 个月
- 第二阶段（精度优化）：3-6 个月

## 5. 验收标准

### 5.1 功能验收
- 所有功能需求（F2.x）实现并通过测试
- 提供完整的使用文档

### 5.2 性能验收
- 在测试集上整体识别率 ≥ 90%
- 单张影像处理时间 < 5 分钟

### 5.3 质量验收
- 代码审查通过
- 测试覆盖率 ≥ 80%
- 无严重 bug

## 6. 术语表

- **GSD**：Ground Sample Distance，地面采样距离
- **IoU**：Intersection over Union，交并比
- **RTK**：Real-Time Kinematic，实时动态定位
- **PPK**：Post-Processed Kinematic，后处理动态定位
- **图斑**：具有相同地物类型的连续区域
